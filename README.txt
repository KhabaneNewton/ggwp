ABYNXZ - SITUS PERSONAL BRANDING PENDAKI
========================================

ISI PAKET
  index.html   Kerangka halaman: semua teks, bagian, dan tautan WhatsApp.
  style.css    Seluruh tampilan: warna, ukuran, hero, blok transisi, kartu, galeri 3D.
  app.js       Seluruh gerak: loading, scroll meluncur, transisi, panel bab, ID/EN, kontur.
  images/      18 foto 1920x1920 (andong, telomoyo, merbabu, prau, bismo, kembang, galeri-1..12).

CARA PASANG (HOSTING)
  1. Ekstrak zip. Upload index.html, style.css, app.js, dan folder images
     ke folder utama hosting (public_html di cPanel) tanpa mengubah susunannya.
  2. Netlify / Cloudflare Pages / GitHub Pages: seret folder hasil ekstrak (bukan file zip).

CARA UBAH CEPAT
  Teks            : index.html (cari kata yang mau diganti). Versi Inggris ada di atribut data-en.
  Warna           : style.css, baris :root paling atas (--neon = warna hijau neon).
  Lama loading    : app.js, angka 4650 pada "DUR" (milidetik, 4650 = sekitar 5 detik).
  Lama meluncur   : app.js, angka TAU = .45 (sekitar 3 detik berhenti).
                    Lebih kecil = lebih cepat berhenti (.25 = sekitar 2 detik), lebih besar = lebih lama.
  Nomor WhatsApp  : index.html, cari 628172864881 dan +62 817-2864-881.
  Ganti foto      : timpa file di folder images dengan nama yang sama (1920x1920).
